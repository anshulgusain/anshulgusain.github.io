# Anshul Gusain — Developer Portfolio

A standalone recruiter-first portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser. No installation or build step is required.

## Publish on GitHub Pages

1. Place these files at the root of the `anshulgusain.github.io` repository.
2. In GitHub repository settings, open **Pages**.
3. Choose **Deploy from a branch**, then select the main branch and root folder.

The site uses relative asset paths and is ready for `https://anshulgusain.github.io/`.
